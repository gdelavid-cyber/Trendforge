# Trendly — Project Instructions

## Product Direction
- **Trendly is the Companion Economy**: users forge AI companions (visual identity, personality), point them at trending money-tasks, and the companion executes real work with one-click approval gates.
- Canonical design: `docs/superpowers/specs/2026-08-23-trendly-companion-platform-design.md`
- Naming: the product is **Trendly** everywhere; "TrendForge" is retired placeholder naming.

## Overview
Trendly is a production-grade platform where users forge, customize, and deploy AI companions that do real work for them (research, files, email, posts) with full visual identity, web4 ownership, and one-click execution.

## Honesty Model (S6+, non-negotiable)
- Companions do REAL work or report BLOCKED — they never fake outcomes.
- Income shown anywhere = ledger-backed real money only (`LedgerEntry` credits: deposits / trade proceeds / battle pots). Self-reported task earnings were removed and zeroed.
- Gamification XP derives from completed moves, never from dollars.
- Agents start at $0; on-chain USDC deposits (memo-matched reference codes) are the only way funds enter.

## Architecture
- 17 pages: Landing, Pricing, Legal, Stories, Auth (signin/signup/forgot-password), Dashboard, Tasks, Task Detail, Trends, Community, Marketplace, Profile, Story Submit, Admin, Launch Environment
- 25+ API routes covering tasks, trends, community, marketplace, stories, Stripe payments, admin, pipeline
- Prisma ORM with 13 models
- Stripe subscriptions (Free/Premium $19/Pro $49/Enterprise $999)
- LLM-powered 7-stage pipeline (ingest → extract → validate → categorize → generate → quality-filter → risk-classify → personalize)
- S3 file uploads for screenshots/templates
- Email notifications via Abacus AI notification API (5 types registered)

## Key Patterns
- Server components fetch data → pass serialized props to `_components/*-client.tsx` client components
- All API routes have `export const dynamic = 'force-dynamic'`
- Pipeline API routes protected by `x-api-key` header matching `PIPELINE_API_KEY`
- Stripe webhook uses raw body for signature verification
- Email functions gracefully degrade (log to console if API key missing)

## Admin Credentials
- Admin, hidden-test and demo accounts are seeded by scripts/seed.ts from environment variables (ADMIN_EMAIL, ADMIN_PASSWORD, HIDDEN_TEST_EMAIL, HIDDEN_TEST_PASSWORD, DEMO_PASSWORD) defined in nextjs_space/.env — never committed to the repository.
- Hidden test account is separately seeded (never exposed)

## External Integrations
- Stripe: keys in .env (STRIPE_SECRET_KEY, STRIPE_PUBLISHABLE_KEY, STRIPE_WEBHOOK_SECRET)
- SendGrid: placeholder only (SENDGRID_API_KEY=placeholder_not_configured)
- Pipeline: PIPELINE_API_KEY (UUID) for external agent authentication

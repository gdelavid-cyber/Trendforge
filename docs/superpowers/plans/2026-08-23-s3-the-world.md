# S3 Implementation Plan — The World (3D Playground)

Spec: `docs/superpowers/specs/2026-08-23-trendly-companion-platform-design.md` §5.
Goal: `/arena` becomes **The World** — a GTA-flavored explorable neon plaza
where users walk their customized companion around and show off owned
cosmetics. No combat. Pure identity showcase + fun.

## Ground truth
- `components/avatar/stage3d/Stage3DCanvas.tsx`: Mannequin rig pattern +
  `useGLTF` cosmetic rendering — lift these into a walking character.
- Arena server page already loads session user + web4Agents + merged catalog
  → reuse its loadout assembly to dress the in-world companion.
- drei 9.x installed (`OrbitControls`, `Environment`, `useGLTF` proven).
  No physics lib — movement is kinematic custom controller (no new deps).
- Old fighter-select UI (`arena-select-client.tsx`) gets unmounted; file stays
  in repo (demote ≠ delete).

## Tasks

### T1 — World scene foundation (`components/world/`)
`WorldCanvas.tsx`: continuous-loop `<Canvas>` (dpr capped), fog, dark sky,
neon ground grid (large plane + grid helper shader-lite), ring of emissive-
edged building blocks (instanced-ish simple meshes), scattered glow props,
ambient+directional+cyan rim lighting.
Verify: compiles standalone behind dynamic ssr:false import.

### T2 — Companion character in-world
`CompanionAvatar.tsx`: Mannequin-derived rig at human scale; equipped-cosmetic
GLB attachments where loadout provides them (headwear/wings via same slots
Stage3D uses); idle hover bob; walk-cycle approximation (bob + slight tilt
while moving); aura effect = point light tinted by AURA item color.
Verify: renders inside WorldCanvas with empty loadout (mannequin).

### T3 — Controls + third-person camera
`useWorldControls.ts`: keydown/keyup tracking (WASD + arrows, Shift sprint,
Space jump). Kinematic mover with acceleration/damping, world-bounds clamp.
Camera: springy follow rig behind companion, mouse-drag orbit optional off —
v1 fixed-angle follow (GTA-lite).
Verify: manual dev-server smoke; unit-test the pure movement math (extract
`computeNextPosition(state, keys, dt)` as pure fn + tests).

### T4 — HUD overlay
DOM layer above canvas: controls legend, companion name plate, equipped
cosmetics chips (from loadout), "The World // Trendly" wordmark. Mobile
note ("best on desktop") without blocking.
Verify: tsc; visual classes consistent with cyan identity.

### T5 — Page swap
`app/arena/page.tsx` keeps data loading, renders `<WorldClient loadout …/>`
(dynamic ssr:false) instead of fighter-select; metadata title stays
"The World // Trendly". Old client unmounted (file preserved).
Verify: page 200 signed-out (spectator cam drifting through city), full
experience signed-in.

## Ship checklist
tsc + Vitest green → push → Vercel probe `/arena` 200 + canvas chunk loads
(no console-fatal SSR errors) → manual desktop walkthrough.
